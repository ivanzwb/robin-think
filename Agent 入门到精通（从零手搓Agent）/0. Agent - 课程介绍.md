# Agent - 课程介绍

## 课程概述

本课程是 **Agent（智能体）入门到精通的完整路径**，从零开始手把手教学，帮助学员系统掌握 Agent 的理论基础、工程实践和实际应用。

你是否曾惊叹于 ChatGPT、Claude 等 AI 的强大能力？你是否想象过 AI 能像人一样自主思考和行动？这门课程将带你从 "使用 AI" 跨越到 "创造 AI Agent"，掌握构建真正自主智能体的核心技能。

**一句话概括**：不做 AI 的使用者，要做 AI 的创造者。

---

## 为什么要学习 Agent？

### AI 发展的必然趋势

| 阶段                  | 核心能力    | 代表产品                  | 用户角色  |
| ------------------- | ------- | --------------------- | ----- |
| **Chatbot**（对话式 AI） | 回答问题    | ChatGPT, Claude       | 被动提问者 |
| **Copilot**（辅助驾驶）   | 协助完成任务  | GitHub Copilot        | 协作者   |
| **Agent**（智能体）      | 自主规划和执行 | AutoGPT, Claude Agent | 任务授权者 |

### Agent 能做什么？

- **自动化复杂任务**：代替人类完成多步骤工作流
- **自主决策**：根据环境反馈动态调整策略
- **持续学习**：通过交互不断优化表现
- **跨系统协作**：连接多个工具和服务

## 课程大纲

### 第一章：理论与思考

**核心问题**：什么是 Agent？智能体与 chatbot 有何本质区别？

**内容包括**：
- Agent 的定义与核心特征
- Agent vs Chatbot vs Copilot
- ReAct、ToT、CoT 等推理技术
- 多 Agent 系统架构
- Agent 的局限性

**学习目标**：建立对 Agent 的系统认知，理解底层原理。

---

### 第二章：工程实践

**核心问题**：如何从零构建一个可运行的 Agent？

**内容包括**：
- Agent 架构设计
- 工具调用（Tools & Skills）
- 记忆系统（Memory）
- 规划器（Planner）
- 反思机制（Reflection）
- 主流框架：LangChain、LangGraph、AutoGen
- 实际代码演示

**学习目标**：掌握 Agent 工程化的核心技能，能够动手实现。

---

### 第三章：实例讲解（OpenCode 实战）

**核心问题**：如何基于真实开源代码，手搓一个可运行、可审计、可扩展的 Agent 系统？

**为什么选择 OpenCode？**

- **真实源码可读**：本章基于 `sst/opencode` 的真实工程实现（2.0 分支）
- **架构完整**：覆盖 Agent / Tool Registry / Session Processor / Permission / Compaction
- **工业级链路**：具备权限治理、状态机执行、上下文压缩等生产能力
- **可复刻**：可以按模块拆解逐步实现最小可用 Agent

**内容包括（按真实代码结构）**：
- OpenCode 架构总览（`packages/opencode/src`）
- 模块一：Tools（`tool/registry.ts`, `read.ts`, `edit.ts`, `bash.ts`, `task.ts`, `todo.ts`）
- 模块二：Skills（`skill/index.ts`, `tool/skill.ts`, `session/system.ts`）
- 模块三：Planning（`agent/agent.ts` 的 build/plan 模式 + `tool/plan.ts`）
- 模块四：Memory（`session/summary.ts`, `session/compaction.ts`）
- 模块五：Execution（`session/processor.ts` 工具状态机）
- 模块六：Permission（`permission/index.ts` 的 allow/deny/ask）
- 模块七：ReAct 循环（`session/llm.ts` + `session/processor.ts`）

**学习目标**：通过 OpenCode 真实代码，掌握工业级 Agent 的模块化实现路径，并能复刻最小可用版本。
