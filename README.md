# robin-think

本仓库用于整理知更鸟研习社的课程资料、学习内容与配套资源，后续会持续补充更多课程。

## 项目内容

当前仓库主要包含以下内容：

- 各类课程的 Markdown 正文、章节资料与配图资源
- 按课程主题整理的独立目录，便于后续持续扩展

## 目录结构

以下为推荐的通用组织方式，当前与后续课程均可按此结构扩展：

```text
.
├─ README.md
├─ 课程 A/
│  ├─ 0. 课程介绍.md
│  ├─ 1. 章节内容.md
│  └─ images/
├─ 课程 B/
│  ├─ 0. 课程介绍.md
│  ├─ 1. 章节内容.md
│  └─ images/
└─ 更多课程目录...
```

## 材料说明

材料由知更鸟研习社提供。

知更鸟研习所，以“唤醒潜能，衔来新知”为使命。我们专注打造有温度、有深度的研习内容，摒弃枯燥灌输，提供职场技能与人文素养课程。这里不仅是学习平台，更是开放包容的互助社群，愿做您成长路上的伙伴，见证每一次蜕变与高飞。

## 使用方式

可按课程目录进入对应内容，直接阅读 Markdown 文档，并结合配图或附加资料进行学习。

如需在 GitHub 或其他代码托管平台展示项目说明，仓库首页将默认展示本 README 内容。
