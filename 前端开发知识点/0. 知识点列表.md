    - 适合：高级前端、架构向岗位、需要回答系统设计题的同学。

    - 适合：二轮复习、面试前速记、从提纲到可讲述答案的过渡。

### 🗺️ 推荐复习顺序

1. 先完成 `JavaScript`，把语言基本盘打稳。
2. 再学习 `TypeScript`，把类型系统和工程实践补齐。
3. 再学习 `Angular`，理解企业级框架工程实践。
4. 再学习 `自动化测试`，补齐质量保障、E2E、BDD 和 CI 能力。
5. 再学习 `浏览器`，补齐底层机制与性能安全认知。
6. 再学习 `DevTools`，强化调试与排障能力。
7. 再学习 `React-Vue 概念与原理入门`，快速建立其他主流框架认知地图。
8. 最后学习 `工程化、架构设计与线上可观测性`，补齐高级岗位的系统化能力。

### 🎯 按岗位选择重点

- **初级前端**
    - 优先看：JavaScript 模块一到模块四、浏览器模块一和模块二。
    - 补充看：TypeScript 的模块一到模块三，理解类型系统和日常建模。
- **中级前端**
    - 必看：JavaScript、TypeScript、浏览器、DevTools 的核心模块。
    - 选看：Angular 的渲染机制、React/Vue 的状态与更新模型、自动化测试中的 E2E/BDD/CI。
- **高级前端 / 架构向**
    - 必看：所有文档中的架构、原理与治理模块。
    - 重点追问：JS 运行时、GC、Ivy/Fiber、编译优化、构建链路、发布策略、线上监控、故障治理与复盘。

### 🔥 高频原理追问清单

- **JavaScript**
    - 为什么浏览器和 Node.js 的事件循环表现不完全一样？
    - 宿主环境、JS 引擎、Web API / libuv 分别负责什么？
    - 微任务为什么会影响渲染时机和交互流畅度？
- **TypeScript**
    - 为什么 TS 类型在运行时拿不到？类型擦除发生在什么阶段？
    - 控制流分析为什么能在分支后自动收窄类型？
    - 模块解析为什么会出现“代码能跑但类型找不到”或相反的情况？
- **Angular**
    - Ivy 为什么不依赖虚拟 DOM？`TView/LView` 分别存什么？
    - DI 查找链是怎么工作的，为什么局部 provider 会覆盖全局？
    - Signals 为什么能做到比全树检查更细粒度的更新？
- **React / Vue**
    - React Fiber 为什么能打断 render 却不能打断 commit？
    - `setState` 为什么会出现旧值问题，batching 和 queue 在其中扮演什么角色？
    - Vue 的 `track/trigger` 和 scheduler 为什么能把多次响应式更新合并到一轮刷新里？
- **浏览器 / DevTools**
    - 一次点击从输入事件到合成提交，中间经过了哪些线程和阶段？
    - Performance 面板为什么能看到长任务，trace event 模型在记录什么？
    - source map 明明上传了，为什么线上堆栈还是还原失败？
- **工程化 / 可观测性**
    - 增量构建为什么能只重算一部分任务，它依赖什么任务图或模块图？
    - 远程缓存为什么会“命中错”或“失效错”，缓存 key 应该包含什么？
    - release、commit hash、asset hash、source map 版本为什么必须强一致？
